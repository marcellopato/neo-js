# Language policy

Human-facing output follows `language.profile` and `language.human_outputs` in
`.sdd-agentic-flow/config.yml`. Supported profiles are `en-US` and `pt-BR`.
Keep technical tokens, paths, commands, modes, status values, identifiers, and protocol
names in canonical English. Do not translate them. Both profiles use
`language.bilingual_mode: technical-canonical`.
