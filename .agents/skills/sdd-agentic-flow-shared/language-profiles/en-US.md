# Language profile: en-US

Use English for human-facing explanations, prompts, reports, and guidance.

Keep these tokens canonical:

- commands and paths;
- skill names and pack names;
- modes and status values such as `plan`, `review`, `PASS`, `WARN`, and `FAIL`;
- configuration keys, identifiers, and protocol names.

The profile uses `technical-canonical` bilingual mode. English prose may include
technical tokens without translating them.
